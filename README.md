# ContextOS: Personal AI Memory Infrastructure

> **"Don't remember where you saved it. Just remember what you're looking for."**

ContextOS is a native, privacy-first desktop application that functions as an evolving, persistent, multimodal personal memory system. It automatically observes your authorized local folders, extracts concepts and entities across PDFs, text documents, screenshots, and saved webpages, links them within a **temporal knowledge graph**, and delivers **evidence-grounded hybrid retrieval**.

---

## 🌟 Key Highlights & Core USP

Traditional file search relies strictly on filenames, folders, or simple keyword matches. ContextOS builds an interconnected knowledge representation of your digital life:

1. **Automatic Background Ingestion**: Authorize a folder once (e.g. `Downloads`, `Screenshots`, `Research`). ContextOS silently watches with native filesystem observers, hashes files to prevent duplicate processing, and ingests new or modified assets.
2. **Multimodal Understanding**:
   - **Documents**: Preserves page numbers, extracted text, and document metadata via PyMuPDF and python-docx.
   - **Screenshots & Images**: Extracts on-screen text via PaddleOCR and indexes visual embeddings.
   - **Web Content**: Companion Chrome extension (Manifest V3) captures complete pages, articles, or text selections directly to the memory graph.
3. **Temporal Knowledge Graph**:
   - Understands relationship evolution over time (e.g. `Architecture V1` $\rightarrow$ `Superseded By` $\rightarrow$ `Architecture V2`).
   - Retains provenance timestamps, source file linkages, and entity mention frequencies.
4. **Hybrid Contextual Retrieval**:
   - Fuses SQLite FTS5 lexical BM25 matching with dense vector cosine similarity (via Reciprocal Rank Fusion - RRF).
   - Traverses the knowledge graph to enrich answers with connected people, technologies, and project references.
5. **Zero Hallucination Guarantee**: Every answer generated by the assistant is strictly grounded in retrieved evidence with direct source citations.

## 🚀 Getting Started

### Prerequisites

- **Python 3.10+** (Python 3.12 recommended)
- **Node.js 18+** & **pnpm** (or `npm`)
- **Rust toolchain** (installed via `rustup` for building the Tauri binary)

---

### Step 1: Start the Python AI Backend

1. Navigate to the backend directory:
   ```bash
   cd contextos/backend
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   # On Windows:
   .\venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Copy environment configuration:
   ```bash
   copy .env.example .env
   ```
5. Launch the FastAPI server:
   ```bash
   python -m uvicorn app.main:app --host 127.0.0.1 --port 44480 --reload
   ```
   *The backend will automatically create SQLite database tables, initialize FTS5 indices, and start background workers.* Verify health by visiting `http://127.0.0.1:44480/health`.

---

### Step 2: Run the Desktop Application (Frontend & Tauri)

1. Navigate to the project root:
   ```bash
   cd contextos
   ```
2. Install frontend dependencies:
   ```bash
   pnpm install
   ```
3. Run the development server (in browser or native window):
   - **Vite Web Workspace:**
     ```bash
     pnpm run dev
     ```
     Access at `http://localhost:1420`.
   - **Native Desktop Application (Tauri 2):**
     ```bash
     pnpm run tauri dev
     ```

---

### Step 3: Install the Browser Extension (Optional)

1. Open Google Chrome (or any Chromium browser: Brave, Edge).
2. Navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right.
4. Click **Load unpacked** and select the `contextos/extension` directory.
5. Right-click on any webpage or highlighted text and select **"Save to ContextOS"**.

## 🔍 Verification & Demonstration Scenario

To verify the end-to-end autonomous memory pipeline:

1. Launch ContextOS and navigate to **Sources**.
2. Click **Add Monitored Folder** and choose a local directory (e.g., `Documents\TestNotes`).
3. Save or drop a PDF or text file into that folder (e.g., a file containing *"Project Capsule uses PyTorch and React Native, discussed on September 12, 2026"*).
4. Watch the bottom status bar: ContextOS detects the change via Watchdog, computes the file hash, extracts entities, generates MiniLM embeddings, and records memories in SQLite.
5. Navigate to **Ask ContextOS** and query:
   > *"What technology does Project Capsule use?"*
6. ContextOS returns an evidence-grounded answer citing the exact source file and highlights connected entities in the **Knowledge Graph**.

## 🧪 Testing

Run the automated backend test suite:
```bash
cd contextos/backend
pytest
```
The test suite validates:
- SQLite schema generation & foreign key integrity
- FTS5 full-text indexing triggers
- Sentence chunking boundaries & overlap preservation
- Entity & relationship extraction heuristics

## 🔒 Privacy & Local-First Commitment

- **Local Storage**: All files, embeddings, and database records remain in `%LOCALAPPDATA%\ContextOS`.
- **Zero Cloud Transmission**: By default, no personal content is ever uploaded to remote servers.
- **Explicit Access Only**: ContextOS monitors strictly the folders you authorize.
